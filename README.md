# Mothlight Village — downloadable concept atlas

Nine full-resolution generated concept boards, an offline purple-parchment gallery and a measured 120 × 96 proposed village building map for Claude.

Download **Mothlight-Village-Concept-Art.zip**, extract it and open `Mothlight-Village-Concept-Art/index.html`. The gallery works offline with the images beside it. Start Claude at `CLAUDE-HANDOVER.md`; the package also contains the roadmap snapshot, visual decisions, measured SVG, coordinates and generator.

Sections: world and atmosphere; first neighbours; village-life residents; homes and gardens; venues and grand homes; gathering and materials; quests and cinematics; rewards and decorating; building footprint.

Source branch: `art/mothlight-village-concepts`.

Source commit: `3e8e565e613df069c29951afebbb2f7aeac7fa86`.

[Art boards and guide](https://github.com/ShaneNancarrow97/Pumpkin-patch-/tree/3e8e565e613df069c29951afebbb2f7aeac7fa86/voxel/docs/plans/mothlight-village/concept-art)

Take only the concept-art folder or cherry-pick the concept-only commit. The source branch has earlier contractor UI ancestry, which should not be merged solely to take this art. These are planning references, not implemented village gameplay or production sprite sheets.

The archive's SHA-256 and size are recorded in `package-receipt.json`. The ZIP CRC and local file links have been checked, and all nine images decode on desktop, foldable and phone gallery layouts.
