# The mothlight ledger

Extract the ZIP and open Pumpkin-Patch-Mothlight-Ledger.html in your browser.

Open witchy ledger styling: warm parchment, mulberry binding, a desktop spread
and a single readable mobile page, original moth and pressed-botanical margins,
and handwritten Caveat notes. Clear prices and actions use the normal game fonts.
Every font and illustration is embedded; no network is required.

This is the optional contractor real-rule Festival lab for Claude to integrate,
not the main playable farm release. It never opens player saves or boots the game.
163 native cases and145 exact-HTML browser checks pass. Phone/unfolded/landscape
checks are emulations, not physical-device verification.
