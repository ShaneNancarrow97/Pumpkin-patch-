# Pumpkin Patch Voxel · Mothlight full game

This is the complete playable game, with the witchy ledger design applied to
its real menus. Extract the ZIP and open Pumpkin-Patch-Mothlight-Full-Game.html.
All assets are embedded and the existing fullscreen button is included.

Parchment pages, mulberry book edges, moth and botanical marginalia, and
handwritten notes dress the real Manage, upgrade, wardrobe, home and settings
menus. Normal farm play keeps the compact HUD and unobstructed world.

The game runtime script is byte-identical to the standard game build. No save
key, economy, visitor simulation, purchases or control rules are changed.
Real WebGL boot was checked. Browser menu/layout evidence is being recorded
in the source branch. Physical device/file-provider testing is not implied.
