# Pumpkin Patch — boost and helping hands

Download `Pumpkin-Patch-Boost-and-Helping-Hands.zip`, extract it and open the HTML in Safari or Chrome. The direct `.html` file is included here too. Use the existing fullscreen button for the unfolded layout.

New play loop:

- Plant one plot per press.
- Pick one, two or three ripe plots, using the selected owner's trained basket capacity.
- Recruit Shane and Natalie separately, once each; train their planting and watering speed.
- Upgrade boost power and cooling. The small dial fills with use; overheating locks Boost until it cools to 35%.
- Existing shared Helping hands owners keep both helpers after migration.

Find the upgrades under **Manage → Farm → Helping hands / Boost**.
