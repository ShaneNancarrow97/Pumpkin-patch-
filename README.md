Open Pumpkin-Patch-Directional-Characters.html to play the full offline game. The ZIP contains the same HTML. No account, API key or server is required by the game.

This release adds eight-direction movement sheets for Shane and Natalie in their everyday clothes and nine Mothlight neighbours: Elowen, Rowan, Vesper, Mabel, Tansy, Opal, Cinder, Corvus and Baron. Each sheet has 64 movement drawings; Cinder floats. Walking follows actual distance and turns relative to the camera. Existing costumes, tool poses, idle art and pets retain their previous sheets. Eight view sectors are not the historical 15-degree target.

The standalone Sprite Preview offers direction selection and frame scrubbing. The Sprite Pack ZIP includes final source sheets, runtime atlases, metadata and a portable preview; the Claude Patch ZIP contains the incremental source patch series and full handover. Repair inputs are retained in the source repository.
