# Pumpkin Patch — Voiced Mothlight

Download `Pumpkin-Patch-Voiced-Mothlight.zip`, extract it, then open `Pumpkin-Patch-Voiced-Mothlight.html` in Chrome or Safari. The HTML contains the full game, its artwork and the available speech recordings; no API key or internet connection is needed to play.

Use Settings → Introduction → Watch again to hear Shane and Natalie. Mothlight Village opens at farm level 3 from More. Voice and replay buttons appear during introductions, the tour and conversations. Settings has separate music, effects and voice controls.

This build includes 164 ElevenLabs recordings (about 11 minutes): the entire farm introduction, all village tour stops and many Elowen/Rowan chats. The API quota stopped further generation. The remaining 168 authored lines, including quests and other cast members, stay readable as text. Their game actions still work normally. No quest progress, prices or rewards were changed by the voice patch.

Before switching game files, save your existing farm to a file in Settings; load that save in this HTML. This preserves progress when the browser gives downloaded files separate storage.

`Mothlight-Voiced-Explorer.html` is the optional unsaved village preview, separate from your farm save.

The source and Claude handover are on branch `contractor/mothlight-voices`. The patch depends on the earlier `contractor/village-design-and-cast` integration.
