# The Hollow Ledger — achievement plan and UI concept

**Planning/prototype only. These achievements are not installed in the playable game yet.**

Download `Pumpkin-Patch-Achievement-UI-Preview.html` and open it in a browser. It is a standalone interactive concept with sample progress: preview an unlock, click the toast to inspect what was done, browse Early/Mid/Late/Secrets, and reveal optional secret hints. It writes no game saves or rewards.

Download `Achievement-Plan-Claude-Kit.zip` for the complete 64-entry catalogue, 1,000-point design, evidence audit, dependency matrix, asset brief, source template/builder, preview and verification screenshots.

Proposed structure:16Early,20Mid,16Late,12Secrets. Non-spendable Haunt Score; cosmetic milestones; no recurring income bonuses. The original purple/amber notification is inspired by console achievement behaviour without copying Xbox branding.
