# Achievement art and sound direction

This is an asset brief, not generated production art. The preview uses a few original SVG category emblems to demonstrate hierarchy; it does not contain 64 finished badge illustrations.

Use sculpted, readable silhouettes: carved pumpkins, brass watering cans, paired work gloves, ghost mugs, copper cookware, crooked houses, books, lanterns, tractor wheels, moths and pet portraits. Deep plum enamel, warm brass and soft cream belong to the existing world. Mint is a small earned-state accent. Rare/legendary frames can have moonlit foil but must retain a textual challenge label.

Produce eight coherent badge families, each with distinct centre artwork for its entries: farming; helpers/thermal care; domestic life/books; wardrobe/companions; cooking/cocoa; commerce/guests; attractions; hidden discoveries. Use one shared rim and a consistent light source. Keep small details out of the centre so the badge reads at 44–64 pixels. Secret placeholders use a moth seal/question mark, not the unrevealed final art.

Suggested final atlas: eight by eight icons at 64 pixels each, 512×512 WebP with alpha; retain a separate higher-resolution source board in documentation. Measure the actual display size before shipping and verify dark/light variants. Individual 2K images for every tiny badge would inflate the offline HTML. Category SVG placeholders may be retained for the first implementation slice while artwork is approved.

Motion is CSS/DOM: one badge settle, pill reveal and thin sparkle sweep. No continuous confetti, full-screen bloom or new WebGL lights. The existing farm should remain the visual focus. The prototype's frozen farm screenshot is documentation only and must not be bundled as a new game background.

Sound is an original short celesta/chime phrase with a quiet low confirmation tone, roughly 0.7 seconds. A rare variation adds one note. Do not copy a console platform's logo or audio sting. Prototype audio/haptics are not implemented; production must use game preferences, browser gesture consent and reduced-intensity options.

Cosmetic collection rewards in PLAN.md need their own real catalogue IDs, icons, voxel models and measured wall/shelf/floor anchors. Do not grant placeholder item IDs. Validate cabinet footprint and shelf book directions against the existing universal placement system before enabling those rewards.
