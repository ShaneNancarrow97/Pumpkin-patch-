# The Hollow Hayride — generated design references

These images accompany [Claude handover 32](../../handovers/32-haunted-hayride-roadmap.md). They describe a proposed second attraction; the full route and player ride-along are not yet integrated into the game.

- [Route map](route-map.png): one clockwise woodland circuit, rear boarding, scarecrow pumpkins, spider tunnel, bride's mansion, paranormal pursuit, zombie prison bus and return/unload.
- [Tractor and wagon sheet](tractor-design.png): rear boarding hero, front/side/rear views and a passenger-eye ride-along inset. Pine-green tractor, brass details, burgundy hubs and walnut hay wagon.
- [Native voxel vehicle prototype](../../contractor-patches/haunted-hayride/prototype/README.md): inspectable model code, geometry checks and an offline preview builder for Claude.
- [Art manifest](manifest.json): generator, reference, source files, dimensions and SHA-256 hashes.

The final PNGs are unmodified image-generation outputs. The farm screenshot was inspected before use as a style reference; the route illustration was then refined to clarify the continuous loop. These are concept references, not measured construction drawings or UV atlases. Claude must validate site allocation, seats, pivots, vehicle clearance, rear access and native collision before integrating the attraction. The native prototype's declared anchors and measured geometry are the starting authority for dimensions.
