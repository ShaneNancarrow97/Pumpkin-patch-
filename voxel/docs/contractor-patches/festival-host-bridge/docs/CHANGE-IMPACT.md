# Change assessment · 2 November 2026

## Present scope

Only the new contractor folder changes. No production entry imports the bridge,
lab or desk. The lab imports real model/rule modules as a consumer, never boots
the live scene/main/storage and never reads player storage. The build allowlist
checks actual esbuild inputs, including embedded fonts and normalized JSON paths.

The prior matrix did not recognize new bridge paths; `initial-unmapped.json`
preserves that honest initial failure. The new overlay extends rather than edits
the delivered matrix. Its base revision and SHA-256 pin force review if the base
changes. The combined map has 32 domains and 103 semantic links. This avoids
mistaking an unrecognized new subsystem for a safe zero-impact change.

The final semantic report covers all new source/document/tool/test paths outside
captured verification outputs. `current-impact.json` records direct domains,
transitive current consumers and conditional future integrations. The actual
parsed graph in `import-impact.json` separately verifies the new folder's scope
against the production entry and private lab; it does not infer gameplay safety
from imports alone.

## Conditional integration consequences

- **Wallets and stock:** live producer insertion must happen after confirmed
  debit and preserve capacity retry facts without paying again.
- **Save lifecycle:** add versioned origin bindings/departure evidence to saved
  in-flight visits; persist world plus queue together and preserve future data.
- **Attractions:** hooks inside departure/unloading transitions are needed to
  handle large time steps, replaced convoys, repeats and bought-mid-trip routes.
- **House rewards:** catalogue/bounds plus atomic or idempotent entitlement/item
  ownership are necessary before any physical grant can ship.
- **Live UI and controls:** adopting the desk requires farm HUD/focus/controller
  tests and world-obstruction review, not only the isolated page's viewport tests.

Those consequences are explicitly conditional edges. They are not silently
executed suggested checks or claimed installed features. Run the new impact tool
again when Claude changes a producer contract or activates an integration edge.
