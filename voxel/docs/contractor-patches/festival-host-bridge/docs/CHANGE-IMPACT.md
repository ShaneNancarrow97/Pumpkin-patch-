on `contractor/mothlight-game-ui`; this folder remains a separate private rule lab.

not overwritten. The base revision and SHA-256 pin force review if the base

## Conditional integration consequences

- **Wallets and stock:** insert future live producers after confirmed debits and
  preserve retry facts without paying again.
- **Save lifecycle:** explicitly migrate originating bindings and paid departure
  evidence; persist world and queue together and preserve unsupported future data.
- **Attractions:** capture departure/unloading internally so large steps, convoy
  replacement, repeat visits and bought-mid-trip routes cannot invent completion.
- **House rewards:** register catalogue/bounds and atomically or idempotently
  resolve entitlement plus physical ownership before any live grant ships.
- **Live UI:** port the material layer separately from the prepared fixture. Check
  existing HUD/focus/controller selectors, safe areas, playfield obstruction and
  palette/contrast in the real game. The live Mothlight work is a separate branch.

Those are conditional edges, not installed features or automatically run commands.
Run the impact review again when producer contracts or live integrations change.
