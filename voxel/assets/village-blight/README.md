# Cursed spores

Painted red fungal caps, violet ooze and a glass spore vial for the village's
blight material, quest markers and requirement lists. Actual generated art;
the packing script only crops, scales and adds transparent margins.

Runtime: `cursed-spores.webp`, 128px RGBA with a 6px inset. See `manifest.json`
for byte count and source/runtime hashes, and `contact-preview.jpg` for native,
64px, 32px and 24px legibility. `source.png` and the exact prompt are retained.

Rebuild from `voxel/`:

```sh
python tools/bake-village-blight-icon.py
```
