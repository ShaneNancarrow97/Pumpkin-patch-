Pumpkin Patch Voxel — Mothlight Recovery

Open Pumpkin-Patch-Mothlight-Recovery.html in a modern browser. The game and its assets are contained in that file; no server is required.

This update restores live WebGPU walking atlas changes, reduces repeated walking geometry uploads and HUD work, fades fine grass and tiny effects with distance, restrains sky highlights and adds three paired farm/village colour keepsakes.

Existing save version 20 is retained. If opening a new downloaded filename uses a different browser storage location, export your save from the previous game and import it here.

WebGPU is capability-selected; WebGL remains the fallback. The desktop software browser tests do not establish physical phone or TV frame rates. This package contains HTML, not an Android APK.
