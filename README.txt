PUMPKIN PATCH VOXEL - VILLAGE SETTINGS

OPEN THE GAME
Extract this ZIP first. Open Pumpkin-Patch-Village-Settings.html in a
current Chrome or Edge browser. The single HTML contains the game and
assets; it works offline and needs no installer. On Android, use your
Files app to open the extracted HTML with a browser that supports local
HTML, rather than a document preview. This download is not an APK.

KEEP YOUR EXISTING FARM
Before changing versions, open your current game and go to Settings >
Your farm's save > Save to a file. Keep the downloaded JSON backup.
In this version, open the same section and tap Load a save file, select
the JSON and confirm the farm shown in the preview. Use a touch or mouse
click for the browser's file picker. The game also keeps the previous
farm under Undo the last load. If file saving is unavailable, use Share
or Backup as text in that section.

The farm normally saves in this browser's local storage. A different
browser, file location or device may use different storage, so transfer
with a save file instead of assuming progress will appear automatically.
Save files record preferences, but loading restores the farm and keeps
the receiving device's own graphics/settings choices.

VILLAGE GRAPHICS
While in the village, tap the gear beside the character/fullscreen
buttons, or open the controller navigation hub and choose Village
settings. All choices apply immediately and save on this device:
- Renderer: Automatic, WebGPU or WebGL. Unsupported WebGPU falls back
  to WebGL; the status line tells you which renderer is in use.
- Post effects: Off, Subtle, Balanced or Rich. Subtle/Rich adjust the
  visual intensity; Off removes the post-effects rendering work.
- Shadows: On or Off.
- Render distance: Near, Balanced or Far, with a gradual mist fade.
- Grass quality: Off, Low, Balanced or High; the ground remains visible.

For a lighter village, try grass Low, distance Near, shadows Off and
post effects Off. For compatibility, select WebGL. Restore defaults
returns to Automatic, Balanced effects, shadows On, Far and High grass.
Village changes leave the farm's own glow/shadow settings intact.
