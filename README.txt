Pumpkin Patch — Mothlight Green contractor build
8 November 2026

PLAY: Open Pumpkin-Patch-Mothlight.html in Chrome or Safari. It contains the full voxel game and its assets; no server or connection is needed after download. Use the game's fullscreen control.

Mothlight unlocks at patch level 3: More → Mothlight Village, or Elowen's letter. Complete the tour (or Skip tour), meet Rowan, then Elowen. Progress saves with the farm. The introduction clears the village requirement for level 4.

Existing farms: use the game's Save file / Load file controls to transfer progress if your browser treats a new downloaded file as a separate location. No reset is required.

Mothlight-Village-Explorer.html is a separate unsaved preview of the wider valley. Its Restored and Everyone switches do not unlock anything in a farm save. Later districts are still future chapters in the saved game.

New: nine painted NPC identities with six poses each; compact purple village menus; saved Green quests, gathering and Rowan's stall; three existing interiors connected to gameplay; collision-aware walking; smaller conservatory glow.
