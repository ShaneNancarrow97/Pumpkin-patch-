Pumpkin Patch Voxel — Village Detail Polish

Open Pumpkin-Patch-Village-Detail-Polish.html in a modern browser. Everything is embedded in that file; no server is required.

This pass reduces repeated texture and lamp work, avoids rescanning stationary grass, and suspends invisible outdoor animation inside homes and caves. Close-up detail and the existing long distance fades are retained. It includes the previous walking, violet-sky and shared keepsake fixes.

Saves remain version 20. If a new downloaded filename uses a separate browser storage location, export your save from the previous build and import it into this one.

WebGPU is capability-selected with WebGL fallback. Software-browser checks do not certify physical phone or TV frame rates. This package contains HTML, not an APK.
