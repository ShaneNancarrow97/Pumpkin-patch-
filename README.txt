Pumpkin Patch Voxel — Smooth Village

Open Pumpkin-Patch-Smooth-Village.html in a current browser. Everything needed
by the game is embedded in that file; no server or asset downloads are needed.
On Android, extract the ZIP first, then open the HTML with your browser.

Before changing files, use the old game's Settings to export your save. Import
that save in the new file if the browser treats its location as new storage.
Existing version-20 saves, quest progress, purchases and earned looks remain
compatible. Keep your export as a backup.

This release reduces distant resource checks, shares geometry inspection,
retires detached GPU materials, and avoids redundant WebGPU shadow passes.
Nearby visual detail and resolution are preserved. Actual frame rate depends
on your device; software browser verification is not a phone/TV FPS guarantee.
WebGL remains available as the fallback renderer.

Outfits > Village now collects Shane and Natalie's village rewards together.
The Moonlit mummy pair has a village quest route as well as existing late-game
rewards. Moonfern, Mulberry supper and Ghostlight are exclusive earned colour
pairs. Unlock clues are shown in the collection; Wear look equips an earned
colour and its matching original outfit for free. Awards never auto-equip.
