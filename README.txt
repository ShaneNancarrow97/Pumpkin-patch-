Pumpkin Patch — Home & Kitchen contractor build

Extract the ZIP and open Pumpkin-Patch-Home-and-Kitchen.html in Chrome or Safari.
The single HTML contains the complete game, artwork, fonts and audio. Use the
fullscreen button in the top bar. Existing browser save data uses the same key.

Includes detailed voxel furniture, multiple paid copies, larger room budgets,
wall dragging with height, bathroom wing, plain walls and animated appliances;
Maisie's simpler cooking screen, single-tap purchases, faster visitors and
a fifteen-minute active-game-time shelf life for unsold pumpkin stock.
